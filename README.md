# georgios-karakostas.com

Source for [georgios-karakostas.com](https://www.georgios-karakostas.com).

Built with [Pelican](https://github.com/getpelican/pelican). Deployed via [Cloudflare Pages](https://pages.cloudflare.com/).

Frontend vendor assets that require runtime script execution are checked into
`theme/static/vendor/` so the published site does not depend on third-party CDNs
for MathJax, Vega, or GLightbox.
